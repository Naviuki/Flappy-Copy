# Flappy Copy 1.0.1

A small Flappy Bird style game for **Unity 6.5 (6000.5.1f1)**, URP 2D. Every sprite and every sound is
generated by the project itself — no downloaded art, no paid packages.

Небольшая игра в стиле Flappy Bird на **Unity 6.5 (6000.5.1f1)**, URP 2D. Все спрайты и звуки создаются самим
проектом — без скачанных картинок и платных пакетов.

---

## English

### Downloads

| Platform | Archive | How to play |
|---|---|---|
| Windows x64 | `FlappyCopy-Windows.zip` | unpack and run `Windows/FlappyCopy.exe` |
| Linux x64 | `FlappyCopy-Linux.zip` | unpack and run `Linux/FlappyCopy.x86_64` (make it executable if needed) |
| WebGL | `FlappyCopy-WebGL.zip` | serve the unpacked `WebGL/` folder (the one with `index.html`) with any static web server and open it in a browser |
| Android | `FlappyCopy-Android.apk` | install on an Android 8.0+ (API 26) device |

### Controls

- **Space**, left mouse button, touch or the full-screen button: start, flap, restart.
- **R**: restart after a crash.
- **SOUND** (top right): mute / unmute, remembered between runs.

### Linux note

The Linux archive is a plain zip, which does not keep the executable bit. After unpacking, run

```bash
cd Linux
chmod +x FlappyCopy.x86_64
./FlappyCopy.x86_64
```

### Notes

- The game is endless: clear pipe pairs to score, the best score is kept on the device.
- Every archive keeps its build in a folder named after the platform (`Windows/`, `Linux/`, `WebGL/`).
- WebGL fills the browser window and works on desktop and mobile browsers.
- `VERSION.txt` lists the SHA-256 of every archive.

## Русский

### Загрузки

| Платформа | Архив | Как запустить |
|---|---|---|
| Windows x64 | `FlappyCopy-Windows.zip` | распакуйте и запустите `Windows/FlappyCopy.exe` |
| Linux x64 | `FlappyCopy-Linux.zip` | распакуйте и запустите `Linux/FlappyCopy.x86_64` (при необходимости дайте права на запуск) |
| WebGL | `FlappyCopy-WebGL.zip` | отдайте распакованную папку `WebGL/` (ту, где лежит `index.html`) любым статическим веб-сервером и откройте в браузере |
| Android | `FlappyCopy-Android.apk` | установите на устройство с Android 8.0+ (API 26) |

### Управление

- **Пробел**, левая кнопка мыши, касание или полноэкранная кнопка: старт, взмах, рестарт.
- **R**: рестарт после падения.
- **SOUND** (справа сверху): выключить/включить звук, выбор запоминается.

### Замечание для Linux

Linux-архив — обычный zip, а zip не сохраняет бит выполнения. После распаковки выполните

```bash
cd Linux
chmod +x FlappyCopy.x86_64
./FlappyCopy.x86_64
```

### Примечания

- Игра бесконечная: проходите пары труб и набирайте очки, рекорд сохраняется на устройстве.
- В каждом архиве сборка лежит в папке с именем платформы (`Windows/`, `Linux/`, `WebGL/`).
- WebGL занимает всё окно браузера и работает на настольных и мобильных браузерах.
- В `VERSION.txt` указаны SHA-256 всех архивов.
